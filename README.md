# robotautomation

# to run the test

1. Clone github repository

2. Install python

3. Install dependencies:
    pip install -r requirements.txt
    or do it manually one by one

    pip install robotframework
    pip install robotframework-requests

4. Set token from go rest api in resources/variables.robot files

5. Run it from terminal by type:
    robot test-suite/users.robot

6. You can view the result on report.html
